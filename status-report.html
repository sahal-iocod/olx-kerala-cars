Known limitations

  • Model and transmission can't be filtered server-side by OLX's API — enforced locally instead (works, but rare models depend on being inside the newest 100 fetched).
  • First run after changing filters sends a burst of notifications for the existing backlog.
  • The HTML fallback path has no seller or location-ID data, so those checks pass everything through when the API is down.
  • KYC-verified sellers are rare in the live data — the "verified" filter options may match almost nothing.
  • The old Telegram token is still in git history; regenerate it via BotFather before the repo ever goes public.
  • The web UI has no authentication and listens on all interfaces — fine at home, not on a public server.

Roadmap

Tier 1 · Do next

Make it dependable

  • Run as a service (launchd on the Mac mini, or a small VPS). Everything else is pointless if the bot is off when the right car is posted.
  • Health alerts — a Telegram message when checks keep failing. Silent death is the main failure mode of any scraper.
  • Finish the rare-car filter — the paused module. Already half-built and scoped.
Tier 2 · Big value adds

Better alerts, wider view

  • Photos in Telegram — the API already returns image URLs; sendPhoto makes alerts instantly judgeable.
  • Multiple filter profiles — watch a Swift 2015 and a rare-car search at the same time, each labeled in its alerts.
  • One-time full market sweep — paginate everything matching a filter once, on demand, to see the whole market before alerts take over.
  • Nearby-areas toggle — opt back into OLX's relaxed radius when strict location is too narrow.
Tier 3 · Later

From notifier to market tool

  • SQLite + price history — keep every sighting; flag re-posts and price drops on the same car.
  • Deal scoring — compare a listing's price to the average for its model/year and mark underpriced ones.
  • Telegram bot commands — change filters, pause, or ask for status from chat instead of the web UI.
  • Results dashboard — a page in the web app showing matched cars with photos, instead of scrolling Telegram.
